# robots.txt for the whole allan-nava.github.io host.

# Crawlers read robots.txt **only from the host root**, so this one file speaks
# for every project site published under allan-nava.github.io/<repo>/ too. Each
# of those is a separate Jekyll/Hugo build with its own sitemap, which is why
# there is one Sitemap: line per site rather than one for the host.
#
# The per-project Sitemap: lines are GENERATED, not hand-maintained: they come
# from _data/pages_sitemaps.yml, which scripts/sync_robots_sitemaps.rb rebuilds
# in CI (robots-sync.yml). It lists only Allan-Nava-owned GitHub Pages sites
# whose sitemap.xml actually returns 200 — a declared-but-missing sitemap wastes
# crawl budget, so a site that ships no sitemap simply doesn't appear until it
# does. To change what's listed, don't edit here: add jekyll-sitemap / Hugo
# sitemap output to the source repo, or adjust _data/robots_sync.yml.
